## 🚀 Key Features

- 📊 **Financial Analytics** — Interactive revenue charts with daily, weekly, monthly, and yearly filters.
- 🌐 **Traffic Insights** — Interactive traffic acquisition charts for direct, referral, and search traffic.
- 💼 **Deal Management** — Create, edit, delete, search, sort, and manage business transactions.
- 📁 **CSV Export** — Export deal records for reporting and analysis.
- 🧭 **21 Navigation Modules** — Explore analytics, commerce, productivity, UI components, settings, and developer documentation.
- 🎨 **Premium UI Design** — Vibrant pink, purple, cyan, and deep navy with a glossy 3D-inspired sidebar emblem.
- 📱 **Responsive Interface** — Designed for modern screens and adaptable layouts.
- 💾 **Local Persistence** — Save supported changes and preferences using browser local storage.
- 🔔 **Notifications & Preferences** — Manage notifications and customize supported settings.
- 🧩 **Advanced UI Components** — Carousels, accordions, radial progress, forms, editors, charts, tables, and popups.
- 🛡️ **Error Pages** — Dedicated interfaces for 404, 403, 500, and offline states.

## 🛠️ Tech Stack

| Technology | Purpose |

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/GhousDeveloper/lector-analytics-dashboard-website.git

# Enter the project directory
cd lector-analytics-dashboard-website

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL shown in your terminal to explore the dashboard.

## 🧪 Testing

The project includes automated testing tools for validating functionality and browser interactions.

```bash
# Run the project's configured test script
npm test
```

**Note:** Run the test command if the `test` script is configured in `package.json`. Playwright tests may require separate configuration.
